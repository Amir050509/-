# Круг

Стартовый проект социальной сети на Yii2. Сейчас это интерактивный демонстрационный интерфейс: публикации, реакции, комментарии, подписки, профиль, тема и настройки сохраняются в `localStorage` текущего браузера. Серверная регистрация пользователей, общая база публикаций и обмен между устройствами пока не подключены.

## Запуск

Требуются PHP 8.1+, Composer и расширения `mbstring`, `openssl`, `pdo` и `fileinfo`.

```bash
composer install
composer run-script serve
```

Откройте `http://localhost:8080`. Альтернативно можно запустить `php -S 0.0.0.0:8080 -t web`.

## Возможности демо

- Адаптивная русскоязычная лента и поиск по публикациям.
- Создание публикаций с текстом и локальным фото до 5 МБ.
- Реакции, комментарии, закладки, копирование ссылки и скрытие публикаций.
- Черновик публикации, загрузка дополнительных постов, фильтры ленты и поиск по авторам и тексту.
- Редактирование профиля, список друзей с подписками, круги по интересам и отметка участия в событии.
- Истории на 24 часа, сохранённые поздравления и уведомления с отметкой прочтения.
- Светлая и тёмная темы, приватность профиля и настройки уведомлений.
- Данные и действия сохраняются между перезагрузками в браузере; кнопка сброса находится в настройках.

Спецификация токенов, сетки, адаптивных состояний и сборки компонентов для передачи в Figma находится в [`docs/design-system.md`](docs/design-system.md).

Перед публикацией задайте случайный `YII_COOKIE_VALIDATION_KEY`, отключите `YII_DEBUG` и добавьте полноценную серверную аутентификацию и хранилище данных.
