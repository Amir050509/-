# Круг

Стартовый проект социальной сети на Yii2. Вход и регистрация используют серверную SQLite-базу, а пароли сохраняются в виде защищённых хешей. Лента, реакции и настройки пока демонстрационные и хранятся в localStorage конкретного браузера: публикации между пользователями и устройствами ещё не синхронизируются.

## Запуск

Требуются PHP 8.1+, Composer и расширения mbstring, openssl, pdo, pdo_sqlite и fileinfo.

Установите зависимости, создайте таблицу пользователей миграцией и запустите локальный сервер:

    composer install
    php yii migrate --interactive=0
    composer run-script serve

Откройте http://localhost:8080. В XAMPP при ошибке SQLite включите pdo_sqlite в php.ini, перезапустите сервер и повторите миграцию.

## Возможности демо

- Адаптивная русскоязычная лента, поиск и интерактивные элементы.
- Регистрация, вход и выход; пароли хранятся только в виде защищённых хешей.
- Публикации, реакции, комментарии, подписки, фото, тема и настройки в браузерном localStorage.
- Для приватного сайта предусмотрены блокировка ленты для гостей и доступ к регистрации по коду приглашения.

Спецификация токенов, сетки и состояний находится в docs/design-system.md.

## Публичный и закрытый режимы

По умолчанию главная страница доступна всем. Чтобы закрыть её для гостей, задайте переменную окружения KRUG_PRIVATE_MODE=1. Можно дополнительно установить KRUG_INVITE_CODE со случайным длинным кодом: без него посетители не смогут создавать аккаунты. Передайте этот код только приглашённым людям. Если код не задан, регистрация открыта.

Для реального публичного сайта нужен хостинг с PHP 8.1+, SQLite (pdo_sqlite) и HTTPS. Загрузите проект на хостинг, укажите web-root на папку web, задайте там переменную YII_COOKIE_VALIDATION_KEY случайным длинным значением и выполните php yii migrate --interactive=0 один раз. Не запускайте публичный сайт через встроенный PHP-сервер или localhost.

Чтобы публикации, фото, реакции и круги стали общими между пользователями, понадобится следующий этап: хранение этих данных в серверной базе и проверка прав доступа для каждой публикации. Сейчас авторизация серверная, а данные ленты остаются в браузере.
